# Android 8 数据迁移

Android 8.0 和 8.1 上，旧版和正式版采用不同签名。等普通正式包发布后，再从迁移预发布下载 `termix-migration-v1.4.0.apk`，并从稳定 Release 下载普通正式包。先用迁移包备份数据，再卸载旧版并安装正式版。

1. 在旧版中结束终端会话，停止会修改数据的后台任务。覆盖安装迁移包并打开 Termix。需要先处理旧文件权限或修改数据时，选择“打开旧终端”。处理完成并停止后台任务后，选“返回数据备份”，结束剩余会话并重新打开 Termix。
2. 选择“选择备份保存位置”。把显示的恢复密钥单独保存到密码管理器或记在纸上，然后确认会话已结束、密钥已保存。下一步输入你另存的完整密钥，验证通过后，将 `Termix-backup.tmx` 存到系统“下载”或本机其他目录。
3. Termix 会重新读取整个加密备份并校验。看到完成提示后，先确认保存的备份文件和恢复密钥都在手边，再卸载旧版。
4. 安装正式版并第一次打开 Termix。输入恢复密钥并选择同一个备份文件。恢复完成后关闭并重新打开 Termix，加载旧设置。恢复中断时保留备份与密钥，重新打开 Termix 重试。
5. 在正式版确认数据后自行处理备份文件和恢复密钥。两者合用可以读取备份中的密码、令牌和 SSH 私钥。只恢复自己导出的文件。

备份覆盖 Alpine 和 Arch 的已安装系统与家目录、Arch 安装标记、`local/bin`、`local/lib`、终端颜色配置 `local/colors.properties`、应用的 `files`（包括字体、背景、proot 运行文件和完整的 Alpine 安装归档）、系统当前使用的应用专属外部 `files`、以及 `Settings.xml` 和其原子写入备用文件 `Settings.xml.bak`。恢复保留普通文件与目录的权限和修改时间，以及软链接的原目标。软链接本身使用恢复时的修改时间。Android 拒绝创建硬链接时，各路径会恢复为内容与权限相同的独立文件。外部文件系统的时间精度和权限由 Android 挂载决定。

备份排除应用缓存、未完成的下载和 Arch 安装暂存数据、已可重新生成的 PulseAudio 运行目录、客户系统的 `tmp`、`run` 和 `var/cache` 目录中的临时内容，以及设备节点、命名管道和套接字。进程、终端屏幕与未落盘的数据无法迁移。用 root 创建且应用不可读取的文件需要先在旧环境另行保存。如果导出找不到文件或无法读取，旧版应保留到备份成功。

## 本地验证

- 用 [签名与升级说明](app-updates.md) 生成迁移包和下一版普通包。旧版和迁移包在 Android 8 上分别使用版本码 `14`、`15`，系统认可的签名均为旧证书。普通包使用正式证书，版本码从 `16` 起。
- 归档回归在 `core/main/src/androidTest/java/com/termix/migration/OreoArchiveTest.kt`。它覆盖双系统的数据往返、权限和时间、长绝对软链接及硬链接、错误密钥、加密归档篡改和截断、越界路径、外部目录标识变化、提交中断与已有数据冲突。
- 系统验收分别使用 Android 8.0 和 8.1 的测试设备或模拟器。用旧版创建上述数据，覆盖安装迁移包，保存并验证备份，卸载，安装正式版，恢复后重开。另行验证坏归档和中途强制结束进程的结果。记录旧版和迁移包的签名、正式包的签名、系统版本、备份校验和恢复后的实际文件、链接、权限与设置。
